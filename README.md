## Descripción del Proyecto

Este proyecto es un **PFO1** de la materia *Desarrollo de sistemas web - Front End*,  creado con un estilo esoterismo, misticismo y magia digital. Cada sección es un capítulo del grimorio y cada habilidad una maestría elemental. Aplicando estándares de accesibilidad web, semántica HTML5, diseño responsivo Mobile-First y un sistema de animaciones `@keyframes` con intención narrativa.
